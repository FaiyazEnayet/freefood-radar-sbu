# Freefood-Radar generator update

Copy the contents of this folder into your own checkout when ready. This package did not modify any existing checkout or GitHub.

Scope: this file describes rebuilding the recorded offline demo snapshot from fixed fixtures only. The live public snapshot is generated by `scripts/refresh_sbengaged.py` and described in SBENGAGED-INTEGRATION.md.

Install your repository's original generator dependencies, plus `python -m pip install -r portfolio_ui/requirements.txt`.
Run the original command for `scripts/make_dashboard.py`. Its calculations are unchanged; the final write applies the new local presentation.

To rebuild this exact recorded snapshot without retraining:

`python portfolio_ui/renderer.py --repo freefood-radar --root . --input portfolio_ui/original-dashboard-snapshot.html --output docs/dashboard.html`

The HTML itself needs no Python, network or server.
